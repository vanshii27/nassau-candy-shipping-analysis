# Factory-to-Customer Shipping Route Efficiency Analysis

## Project Overview
This project analyzes shipping route efficiency for Nassau Candy Distributor.

## Objectives
- Analyze route efficiency
- Identify geographic bottlenecks
- Compare shipping modes
- Analyze state and city-level performance
- Develop an interactive Streamlit dashboard

## Tools Used
- Python
- Pandas
- Plotly
- Streamlit

## Project Deliverables
- Research Paper
- Methodology
- Executive Summary
- Streamlit Dashboard

## Dashboard
The project includes an interactive Streamlit dashboard for analyzing route efficiency, geographic performance, shipping modes, and route drill-down insights.

## Dataset
The project uses a project-provided Nassau Candy shipping dataset.
